BuildConfig/..........Config files for the build system.
BuildRoot/............Location of built executables, laid out as they will be on
                      a filesystem.
Images/...............Test disk images, the product of a normal build.
OS/...................Base operating system sources.
  Loader/.............Operating system loader sources.
  SysDebug/...........System debugger.
  Uexec/..............User space runtime (dynamic linker, syscalls, etc).
  Executive/..........MINTIA Executive sources.
    Include/..........Executive-internal header files.
    Ex/...............Generic executive subsystem.
    Hal*/.............Platform hardware abstraction layer.
    Io/...............IO system.
    Ke/...............Kernel (scheduler, exception handling, etc).
    Mm/...............Memory manager.
    Ns/...............Namespace manager.
    Ob/...............Object manager.
    Ps/...............Process manager.
  Headers/............Public operating system header files.
    System/...........User space API header files.
    Executive/........Kernel space (module) API header files.
